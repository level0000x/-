## 第331章：随机过程的一般概念

随机过程（Stochastic Process）是描述随机现象随参数（通常是时间）演变而变化的数学模型。从物理学中的布朗运动到金融中的股票价格，从通信中的噪声分析到生物学中的种群演化，随机过程为这些随时间波动的现象提供了统一的数学语言。本章和下一章建立了随机过程理论的基础框架，为刻画不确定性随时间演化的规律提供了理论支柱。

### 128.1 定义与基本分类

**定义 128.1（随机过程）**：设 $(\Omega, \mathcal{F}, P)$ 是概率空间，$T \subseteq \mathbb{R}$ 是指标集（通常表示时间），$(S, \mathcal{S})$ 是状态空间（通常 $S = \mathbb{R}^d$）。**随机过程** $X = \{X_t\}_{t \in T}$ 是 $T \times \Omega \to S$ 的可测映射族，使得对每个 $t \in T$，$X_t(\cdot): \Omega \to S$ 是随机变量。

**定义 128.2（基本分类）**：根据指标集和状态空间的不同：
- **离散时间**（$T = \mathbb{Z}_{\geq 0}$）vs **连续时间**（$T = [0, \infty)$）
- **离散状态**（$S$ 可数）vs **连续状态**（$S = \mathbb{R}^d$）
- **实值过程**：$S = \mathbb{R}$；**向量过程**：$S = \mathbb{R}^d$；**随机场**：$T = \mathbb{R}^d$

**定义 128.3（有限维分布）**：随机过程 $X$ 的**有限维分布族**定义为对所有 $n \geq 1$ 和 $t_1, \ldots, t_n \in T$：

$$F_{t_1,\ldots,t_n}(x_1,\ldots,x_n) = P(X_{t_1} \leq x_1, \ldots, X_{t_n} \leq x_n)$$

**定理 128.1（Kolmogorov 相容性定理 / 存在性定理）**：设一族有限维分布函数 $\{F_{t_1,\ldots,t_n}\}$ 满足：
1.（对称性）对任意置换 $\sigma$，$F_{t_{\sigma(1)},\ldots,t_{\sigma(n)}}(x_1,\ldots,x_n)$ 是 $F_{t_1,\ldots,t_n}$ 的坐标置换
2.（相容性）$F_{t_1,\ldots,t_n}(x_1,\ldots,x_{n-1},\infty) = F_{t_1,\ldots,t_{n-1}}(x_1,\ldots,x_{n-1})$
则存在概率空间 $(\Omega, \mathcal{F}, P)$ 和随机过程 $\{X_t\}$ 以此族为有限维分布。

**证明**（框架）：令 $\Omega = \mathbb{R}^T$（所有函数 $T \to \mathbb{R}$ 的乘积空间），$\mathcal{F}$ 为柱面 $\sigma$-代数。对每个有限子集 $F \subseteq T$，由 Kolmogorov 延拓定理（Carathéodory 扩展定理 + 相容性条件）可将柱面集上的概率测度惟一延拓到 $\sigma(\mathcal{F})$ 上。Kolmogorov 相容性条件保证了这种延拓的存在性，其本质是 $\mathbb{R}^T$ 上的测度由其在柱面集上的值唯一确定（由测度扩张定理）。$\blacksquare$

**定理 128.2（Kolmogorov-Chentsov 连续性判别法）**：若存在 $\alpha, \beta, C > 0$ 使得对任意 $s, t \in T$，

$$\mathbb{E}[|X_t - X_s|^\alpha] \leq C |t - s|^{1+\beta}$$

则 $X$ 存在连续修正（即存在连续过程 $\tilde{X}$ 使 $P(X_t = \tilde{X}_t) = 1$ 对所有 $t$）。且 $\tilde{X}$ 是局部 Hölder 连续的，指数为 $0 < \gamma < \beta/\alpha$。

**证明**：利用 Chebyshev 不等式，对 $\delta > 0$，
$$P(|X_t - X_s| \geq \delta) \leq C|t-s|^{1+\beta} / \delta^\alpha$$
取 $\delta = |t-s|^\gamma$（$0 < \gamma < \beta/\alpha$）得 $P(|X_t - X_s| \geq |t-s|^\gamma) \leq C|t-s|^{1+\beta-\alpha\gamma}$。应用 Borel-Cantelli 引理于二进有理数集，可证 $\tilde{X}_t = \limsup_{n \to \infty} X_{i/2^n}$（$i/2^n \to t$）几乎处处一致收敛，且极限是 Hölder 连续的。$\blacksquare$

Kolrnogorov 相容性定理是随机过程理论的存在性基石，它确保了在给定所有有限维分布的条件下，相应的随机过程确实存在。这一结果的深刻之处在于，它将随机过程的整体存在性问题归约为有限维分布族的相容性问题——类似于泛函分析中 Hahn-Banach 定理将线性泛函的延拓归约为在子空间上的控制。Kolmogorov-Chentsov 连续性判别法则是随机分析中最常使用的工具之一，它为判断一个抽象过程是否具有连续轨道提供了易于验证的矩条件。例如，对 Brown 运动，$\mathbb{E}[|B_t - B_s|^4] = 3|t-s|^2$（$\alpha=4,\beta=1$），故 Brown 运动有 $\gamma < 1/2$ 的 Hölder 连续路径。

## 第332章：Poisson 过程

### 129.1 定义与基本性质

**定义 129.1（Poisson 过程）**：计数过程 $\{N_t\}_{t \geq 0}$（$N_t$ 表示 $[0, t]$ 内事件发生的次数）称为强度 $\lambda > 0$ 的 **Poisson 过程**，如果：
1. $N_0 = 0$
2. 具有独立增量：对任意 $0 \leq t_1 < t_2 < \cdots < t_n$，增量 $N_{t_2} - N_{t_1}, \ldots, N_{t_n} - N_{t_{n-1}}$ 相互独立
3. 具有平稳增量：$N_{t+s} - N_t \sim \operatorname{Poisson}(\lambda s)$（即均值为 $\lambda s$ 的 Poisson 分布）

**定理 129.1（等价刻画）**：$N_t$ 是强度 $\lambda$ 的 Poisson 过程当且仅当：
(1) $N_0 = 0$
(2) $N$ 具有独立平稳增量
(3) $P(N_t \geq 2) = o(t)$ 当 $t \to 0^+$（即无二重事件）
(4) $P(N_t = 1) = \lambda t + o(t)$

**证明**：($\Rightarrow$) 由 Poisson 分布的性质直接验证：$P(N_t \geq 2) = 1 - e^{-\lambda t} - \lambda t e^{-\lambda t} = O(t^2)$。($\Leftarrow$) 将区间 $[0, t]$ 均匀划分为 $n$ 个子区间。由 (3)(4)，在充分小的子区间内至多发生一个事件且发生概率为 $\lambda t/n + o(1/n)$。$N_t$ 近似为 $n$ 个独立 Bernoulli 试验的和，当 $n \to \infty$ 时二项分布趋于 Poisson 分布。$\blacksquare$

**定理 129.2（等待时间与间隔时间）**：设 $\{T_n\}_{n \geq 1}$ 为 Poisson 过程 $N_t$ 的事件发生时间（$T_n = \inf\{t : N_t \geq n\}$），$\{S_n = T_n - T_{n-1}\}$（$T_0 = 0$）为间隔时间。则 $S_n$ 独立同分布于指数分布 $\operatorname{Exp}(\lambda)$，$T_n$ 服从 Gamma 分布 $\Gamma(n, \lambda)$。

**证明**：$P(S_1 > t) = P(N_t = 0) = e^{-\lambda t}$，故 $S_1 \sim \operatorname{Exp}(\lambda)$。由独立增量性，$S_2$ 与 $S_1$ 独立且同分布。$T_n = \sum_{i=1}^n S_i$ 是 $n$ 个独立指数随机变量之和，故 $T_n \sim \Gamma(n, \lambda)$，概率密度为 $f_{T_n}(t) = \lambda^n t^{n-1} e^{-\lambda t}/\Gamma(n)$。$\blacksquare$

**定理 129.3（Poisson 过程的叠加与分解）**：
- **叠加**：独立 Poisson 过程 $N_t^{(1)}$（强度 $\lambda_1$）和 $N_t^{(2)}$（强度 $\lambda_2$）的和 $N_t^{(1)} + N_t^{(2)}$ 是强度 $\lambda_1 + \lambda_2$ 的 Poisson 过程。
- **分解（随机稀释）**：强度 $\lambda$ 的 Poisson 过程的每个事件独立地以概率 $p$ 标记为类型 I，以概率 $1-p$ 标记为类型 II，则分别得到强度 $\lambda p$ 和 $\lambda(1-p)$ 的独立 Poisson 过程。

**证明**：叠加的正交性由独立增量的和仍然独立保证，且矩母函数 $\mathbb{E}[e^{-\theta(N_t^{(1)}+N_t^{(2)})}] = e^{-t(\lambda_1+\lambda_2)(1-e^{-\theta})}$。分解：对任意 $[0,t]$ 内的事件计数 $N_t = n$，$n$ 个事件的条件分布为均匀分布且相互独立，故类型 I 的事件数条件分布于 $\operatorname{Binomial}(n, p)$，无条件分布为 Poisson($\lambda pt$)。$\blacksquare$

### 129.2 非齐次与复合 Poisson 过程

**定义 129.2（非齐次 Poisson 过程）**：去掉平稳增量条件，允许强度函数 $\lambda(t) > 0$，则 $N_t$ 称为非齐次 Poisson 过程，$N_{t+s} - N_t \sim \operatorname{Poisson}(\int_t^{t+s} \lambda(u) du)$。

**定理 129.4（时域变换）**：若 $N_t$ 是非齐次 Poisson 过程（强度 $\lambda(t)$），则 $N_{\Lambda^{-1}(s)}$ 是标准（$\lambda = 1$）Poisson 过程，其中 $\Lambda(t) = \int_0^t \lambda(u) du$。

**证明**：$\tilde{N}_s = N_{\Lambda^{-1}(s)}$ 的增量为 $\tilde{N}_s - \tilde{N}_r = N_{\Lambda^{-1}(s)} - N_{\Lambda^{-1}(r)} \sim \operatorname{Poisson}(\Lambda(\Lambda^{-1}(s)) - \Lambda(\Lambda^{-1}(r))) = \operatorname{Poisson}(s-r)$。$\blacksquare$

**定义 129.3（复合 Poisson 过程）**：**复合 Poisson 过程** $X_t = \sum_{i=1}^{N_t} Y_i$，其中 $N_t$ 是强度 $\lambda$ 的 Poisson 过程，$\{Y_i\}$ 独立同分布（与 $N_t$ 独立）。$X_t$ 是跳幅为 $Y_i$ 的随机阶梯过程，在保险精算中刻画理赔总额，在金融中刻画股价的跳跃成分。

**定理 129.5**：复合 Poisson 过程的均值、方差和矩母函数为：
- $\mathbb{E}[X_t] = \lambda t \mathbb{E}[Y_1]$
- $\operatorname{Var}(X_t) = \lambda t \mathbb{E}[Y_1^2]$
- $\mathbb{E}[e^{\theta X_t}] = \exp(\lambda t (\mathbb{E}[e^{\theta Y_1}] - 1))$

**证明**：条件于 $N_t$，$\mathbb{E}[e^{\theta X_t} | N_t = n] = (\mathbb{E}[e^{\theta Y_1}])^n$。无条件下：$\mathbb{E}[e^{\theta X_t}] = \sum_{n=0}^\infty (\mathbb{E}[e^{\theta Y_1}])^n \cdot e^{-\lambda t}(\lambda t)^n/n! = \exp(\lambda t(\mathbb{E}[e^{\theta Y_1}] - 1))$。对 $\theta$ 求导即得均值和方差。$\blacksquare$

### 129.3 Poisson 过程的应用

**应用 129.1（排队论）**：M/M/1 排队系统的到达过程为 Poisson 过程，服务时间为独立指数分布。系统的长度过程 $Q_t$ 是连续时间 Markov 链，平稳分布为几何分布 $\pi_n = (1-\rho)\rho^n$（$\rho = \lambda/\mu$ 为负荷因子）。Little 公式 $L = \lambda W$ 给出了平均队长与平均等待时间的基本关系。

**应用 129.2（保险风险理论）**：保险公司在 $t$ 时刻的盈余 $U_t = u + ct - \sum_{i=1}^{N_t} Y_i$，其中 $u$ 为初始资本，$c$ 为保费率，$N_t$ 为理赔次数（Poisson 过程），$Y_i$ 为理赔额。破产概率 $\psi(u) = P(\inf_{t \geq 0} U_t < 0)$ 是精算学的基本研究对象。当 $Y_i \sim \operatorname{Exp}(\mu)$ 时，$\psi(u) = (\lambda/(c\mu)) e^{-(\mu - \lambda/c)u}$。

## 第333章：Brown 运动

### 130.1 Brown 运动的数学定义

**定义 130.1（标准 Brown 运动 / Wiener 过程）**：连续时间随机过程 $\{B_t\}_{t \geq 0}$ 称为 **标准 Brown 运动**，如果：
1. $B_0 = 0$ 几乎必然
2. $t \mapsto B_t$ 几乎处处连续
3. 具有独立增量：对 $0 \leq t_1 < t_2 < \cdots < t_n$，$B_{t_2} - B_{t_1}, \ldots, B_{t_n} - B_{t_{n-1}}$ 相互独立
4. 增量分布正态：$B_t - B_s \sim N(0, t-s)$ 对 $0 \leq s < t$

**定理 130.1（Wiener 的存在性证明）**：标准 Brown 运动存在。

**证明**（利用 Fourier 级数构造——Lévy-Ciesielski 构造）：在 $[0,1]$ 上定义 $B_t^{(0)} = t Z_0$（$Z_0 \sim N(0,1)$）。对 $n = 1, 2, \ldots$，取 $2^{n-1}$ 个独立标准正态变量 $\{Z_{n,k}\}_{k=0}^{2^{n-1}-1}$，定义 Schauder 函数：
$$B_t^{(n)} = \sum_{k=0}^{2^{n-1}-1} Z_{n,k} \int_0^t H_{n,k}(s) ds$$
其中 $H_{n,k}$ 为 Haar 小波。由 Schauder 函数的一致收敛性，$B_t = \sum_{n=0}^\infty B_t^{(n)}$ 在 $[0,1]$ 上一致收敛于连续函数，且 $B_t$ 满足 Brown 运动的所有性质。延拓到 $[0, \infty)$ 用独立拼接。$\blacksquare$

**定理 130.2（Brown 运动的基本性质）**：
1. **标度不变性**：对 $c > 0$，$\{c^{-1/2} B_{ct}\}$ 也是标准 Brown 运动
2. **时间反转**：$\{t B_{1/t}\}$（$t > 0$，$t=0$ 时取 $0$）是标准 Brown 运动
3. **反射原理**：$P(\sup_{0 \leq s \leq t} B_s \geq a) = 2P(B_t \geq a)$
4. **矩**：$\mathbb{E}[|B_t|^p] = \frac{2^{p/2} \Gamma((p+1)/2)}{\sqrt{\pi}} t^{p/2}$

### 130.2 Brown 运动的轨道性质

**定理 130.3（Brown 运动的几乎必然性质）**：
1. 对几乎所有 $\omega$，$t \mapsto B_t(\omega)$ 处处连续但处处不可微
2. Brown 路径在任何区间上的变差 $\operatorname{Var}(B, [0,t]) = \infty$ 几乎必然
3. 二次变差 $[B, B]_t = \lim_{|\Pi| \to 0} \sum_{i=1}^n (B_{t_i} - B_{t_{i-1}})^2 = t$ 几乎必然（依概率收敛）
4. Brown 路径的 Hausdorff 维数为 $3/2$

**证明**：(1) 由 Kolmogorov-Chentsov 连续性判别法（$\mathbb{E}[|B_t - B_s|^4] = 3(t-s)^2$），Brown 运动有 $\gamma < 1/2$ 的 Hölder 连续修正。处处不可微性：考虑差商 $(B_{(k+1)/2^n} - B_{k/2^n}) / (1/2^n)$，由重对数律可证其无界。(2) 在 $[0,t]$ 上的变差 $\sum |B_{t_i} - B_{t_{i-1}}|$ 下界由 $\sum \Delta B^2 / \max|\Delta B|$ 给出，而 $\sum \Delta B^2 \to t$，$\max|\Delta B| \to 0$，故变差 $\to \infty$。(3) 由独立增量性，$\mathbb{E}[(\sum \Delta B^2 - t)^2] \to 0$ 当划分变细，证收敛性。(4) 略。$\blacksquare$

**定理 130.4（重对数律）**：
$$\limsup_{t \to \infty} \frac{B_t}{\sqrt{2t \log \log t}} = 1 \quad \text{a.s.}, \qquad \liminf_{t \to 0^+} \frac{B_t}{\sqrt{2t \log \log (1/t)}} = -1 \quad \text{a.s.}$$

### 130.3 鞅论基本概念

**定义 130.2（鞅）**：设 $\{\mathcal{F}_t\}$ 是滤过（递增 $\sigma$-代数族），$\{M_t\}$ 是 $\mathcal{F}_t$-适应随机过程。若 $\mathbb{E}[|M_t|] < \infty$ 且 $\mathbb{E}[M_t | \mathcal{F}_s] = M_s$ 对所有 $s \leq t$，则 $M_t$ 称为 **鞅**。

**定理 130.5（Brown 运动产生的鞅）**：
1. $B_t$ 是鞅
2. $B_t^2 - t$ 是鞅
3. $\exp(\sigma B_t - \sigma^2 t/2)$ 是鞅（指数鞅）

**证明**：由独立增量性，对 $s < t$，$\mathbb{E}[B_t | \mathcal{F}_s] = B_s + \mathbb{E}[B_t - B_s | \mathcal{F}_s] = B_s$。对 $B_t^2 - t$：$\mathbb{E}[B_t^2 | \mathcal{F}_s] = \mathbb{E}[(B_s + (B_t - B_s))^2 | \mathcal{F}_s] = B_s^2 + 2B_s \mathbb{E}[B_t - B_s | \mathcal{F}_s] + \mathbb{E}[(B_t - B_s)^2 | \mathcal{F}_s] = B_s^2 + 0 + (t-s) = B_s^2 + (t-s)$，故 $\mathbb{E}[B_t^2 - t | \mathcal{F}_s] = B_s^2 - s$。指数鞅：$\mathbb{E}[\exp(\sigma B_t - \sigma^2 t/2) | \mathcal{F}_s] = \exp(\sigma B_s - \sigma^2 s/2) \mathbb{E}[\exp(\sigma (B_t - B_s) - \sigma^2 (t-s)/2)] = \exp(\sigma B_s - \sigma^2 s/2)$，因为 $\mathbb{E}[\exp(\sigma (B_t - B_s))] = \exp(\sigma^2 (t-s)/2)$。$\blacksquare$

**定理 130.6（Doob 可选停时定理）**：设 $M_t$ 是鞅，$\tau$ 是有界停时。则 $\mathbb{E}[M_\tau] = \mathbb{E}[M_0]$。更一般地，若 $\sigma \leq \tau$ 是有界停时，则 $\mathbb{E}[M_\tau | \mathcal{F}_\sigma] = M_\sigma$。

### 130.4 Itô 积分与随机分析

**定义 130.3**（Itô 积分）：设 $f(t, \omega)$ 是 $\mathcal{F}_t$-适应的可测过程且 $\mathbb{E}[\int_0^T f(t)^2 dt] < \infty$。**Itô 积分**定义为：
$$\int_0^T f(t) dB_t = \lim_{|\Pi| \to 0} \sum_{i=1}^n f(t_{i-1}) (B_{t_i} - B_{t_{i-1}})$$
其中极限在 $L^2(\Omega)$ 意义下取。与 Riemann-Stieltjes 积分的关键区别在于：被积函数在左端点取值，使得 Itô 积分是鞅。

**定理 130.7**（Itô 等距）：$\mathbb{E}\left[\left(\int_0^T f(t) dB_t\right)^2\right] = \mathbb{E}\left[\int_0^T f(t)^2 dt\right]$。此等距是 Itô 积分构造的核心，它将随机积分与 $L^2$ 范数联系起来，使得积分可以唯一地从简单过程延拓到一般过程。

**定理 130.8**（Itô 公式，一维情形）：设 $X_t$ 是 Itô 过程：$dX_t = \mu_t dt + \sigma_t dB_t$，$f \in C^2(\mathbb{R})$。则
$$df(X_t) = f'(X_t) dX_t + \frac{1}{2} f''(X_t) \sigma_t^2 dt$$
写成展开形式：
$$f(X_t) - f(X_0) = \int_0^t f'(X_s) \mu_s ds + \int_0^t f'(X_s) \sigma_s dB_s + \frac{1}{2} \int_0^t f''(X_s) \sigma_s^2 ds$$

**证明**（启发式）：Taylor 展开 $f(X_{t+\Delta}) - f(X_t) \approx f'(X_t) \Delta X_t + \frac{1}{2} f''(X_t) (\Delta X_t)^2$。由于 $(\Delta X_t)^2 \approx \mu_t^2 (\Delta t)^2 + 2\mu_t \sigma_t \Delta t \Delta B_t + \sigma_t^2 (\Delta B_t)^2$，其中 $(\Delta B_t)^2 \approx \Delta t$（二次变差），$\Delta t \Delta B_t = o(\Delta t)$。保留 $O(\Delta t)$ 项得 $df = f' dX_t + \frac{1}{2} f'' \sigma_t^2 dt$。$\blacksquare$

**定理 130.9**（多维 Itô 公式）：设 $dX_t = \boldsymbol{\mu}_t dt + \boldsymbol{\sigma}_t d\mathbf{B}_t$（$\mathbf{B}_t$ 为 $m$ 维 Brown 运动，$\boldsymbol{\mu} \in \mathbb{R}^n$，$\boldsymbol{\sigma} \in \mathbb{R}^{n \times m}$），则对 $f \in C^2(\mathbb{R}^n)$：
$$df(X_t) = \nabla f(X_t) \cdot dX_t + \frac{1}{2} \sum_{i,j} (\boldsymbol{\sigma}_t \boldsymbol{\sigma}_t^T)_{ij} \frac{\partial^2 f}{\partial x_i \partial x_j}(X_t) dt$$

### 130.5 随机微分方程

**定义 130.4**（随机微分方程，SDE）：**随机微分方程**形式为：
$$dX_t = b(t, X_t) dt + \sigma(t, X_t) dB_t, \quad X_0 = x_0$$
其中 $b$ 为漂移系数，$\sigma$ 为扩散系数。解 $X_t$ 是一个 Itô 过程。

**定理 130.10**（存在唯一性）：若 $b$ 和 $\sigma$ 满足 Lipschitz 条件 $|b(t, x) - b(t, y)| + |\sigma(t, x) - \sigma(t, y)| \leq K|x-y|$ 和线性增长条件，则 SDE 存在唯一的强解 $X_t$，且 $X_t$ 是 $\mathcal{F}_t^B$-适应的。

**证明**（框架，Picard 迭代）：定义 Picard 迭代序列 $X_t^{(0)} = x_0$，
$$X_t^{(n+1)} = x_0 + \int_0^t b(s, X_s^{(n)}) ds + \int_0^t \sigma(s, X_s^{(n)}) dB_s$$
使用 Itô 等距和 Gronwall 不等式证明 $\mathbb{E}[\sup_{0 \leq t \leq T} |X_t^{(n+1)} - X_t^{(n)}|^2] \leq (CT)^n/n!$，从而 $X_t^{(n)}$ 一致收敛到唯一解。$\blacksquare$

**例 130.1**（几何 Brown 运动）：$dS_t = \mu S_t dt + \sigma S_t dB_t$。由 Itô 公式作用于 $f(x) = \log x$：
$$d(\log S_t) = \frac{1}{S_t} dS_t - \frac{1}{2S_t^2} (dS_t)^2 = \left(\mu - \frac{\sigma^2}{2}\right) dt + \sigma dB_t$$
故 $S_t = S_0 \exp\left((\mu - \sigma^2/2)t + \sigma B_t\right)$。几何 Brown 运动是 Black-Scholes 模型中资产价格的标准模型。

### 130.6 Girsanov 定理与测度变换

**定理 130.11**（Girsanov 定理）：设 $B_t$ 是 $(\Omega, \mathcal{F}, P)$ 上的 Brown 运动，$\theta_t$ 是 $\mathcal{F}_t$-适应过程且满足 Novikov 条件 $\mathbb{E}^P[\exp(\frac{1}{2} \int_0^T \theta_t^2 dt)] < \infty$。定义
$$\frac{dQ}{dP} = \exp\left(-\int_0^T \theta_t dB_t - \frac{1}{2} \int_0^T \theta_t^2 dt\right)$$
则 $Q$ 是 $P$ 的等价概率测度，且在 $Q$ 下，$\tilde{B}_t = B_t + \int_0^t \theta_s ds$ 是 Brown 运动。

**证明**：定义 $Z_t = \exp(-\int_0^t \theta_s dB_s - \frac{1}{2} \int_0^t \theta_s^2 ds)$，由 Novikov 条件，$Z_t$ 是鞅。构造 $Q$ 使得 $dQ|_{\mathcal{F}_T} = Z_T dP|_{\mathcal{F}_T}$。对任意 $0 \leq s < t$ 和 $\mathcal{F}_s$-可测集 $A$，计算 $\mathbb{E}^Q[\exp(i u(\tilde{B}_t - \tilde{B}_s)) 1_A] = \mathbb{E}^P[Z_t e^{i u(\tilde{B}_t - \tilde{B}_s)} 1_A] = P(A) e^{-u^2(t-s)/2}$，故 $\tilde{B}_t$ 在 $Q$ 下是 Brown 运动。$\blacksquare$

Girsanov 定理是数理金融中风险中性定价的数学基础：在风险中性测度 $Q$ 下，折现资产价格是鞅。在统计中，Girsanov 变换用于检测信号——改变漂移相当于测度变换。

## 第334章：Markov 过程与更新理论

### 131.1 Markov 过程

**定义 131.1**（Markov 过程）：$\{X_t\}$ 称为 **Markov 过程**，如果对任意 $s < t$ 和可测集 $A$，
$$P(X_t \in A | \mathcal{F}_s) = P(X_t \in A | X_s) \quad \text{a.s.}$$
即给定现在，未来与过去独立。转移概率 $P(s, x; t, A) = P(X_t \in A | X_s = x)$。

**定理 131.1**（Chapman-Kolmogorov 方程）：对 $s < u < t$，
$$P(s, x; t, A) = \int P(u, y; t, A) P(s, x; u, dy)$$
此方程是 Markov 过程理论的基石，刻画了转移概率的半群结构。

**定义 131.2**（推移算子与 Markov 半群）：定义转移半群 $(T_t)$ 为 $(T_t f)(x) = \mathbb{E}[f(X_t) | X_0 = x]$。则 $T_t$ 满足半群性质 $T_{t+s} = T_t \circ T_s$。对时齐 Markov 过程，生成算子（无穷小生成元）为：
$$\mathcal{L} f = \lim_{t \to 0^+} \frac{T_t f - f}{t}$$

### 131.2 连续时间 Markov 链

**定义 131.3**（连续时间 Markov 链，CTMC）：状态空间可数，转移速率 $q_{ij} \geq 0$（$i \neq j$），$q_i = \sum_{j \neq i} q_{ij} < \infty$。逗留时间 $\sim \operatorname{Exp}(q_i)$，离开后以概率 $p_{ij} = q_{ij}/q_i$ 跳至状态 $j$。Q-矩阵 $Q = (q_{ij})$（$q_{ii} = -q_i$）。

**定理 131.2**（Kolmogorov 向前/向后方程）：转移概率 $P_{ij}(t) = P(X_t = j | X_0 = i)$ 满足：
- **向后方程**：$P'(t) = Q P(t)$，$P(0) = I$
- **向前方程**：$P'(t) = P(t) Q$，$P(0) = I$
解为 $P(t) = e^{tQ} = \sum_{n=0}^\infty \frac{t^n Q^n}{n!}$。

**定义 131.4**（平稳分布）：概率分布 $\pi$ 称为平稳分布，如果 $\pi Q = 0$。对不可约正常返的 CTMC，$\lim_{t \to \infty} P_{ij}(t) = \pi_j$（存在且与 $i$ 无关）。

### 131.3 更新过程

**定义 131.5**（更新过程）：设 $\{S_n\}_{n \geq 1}$ 是独立同分布的正随机变量（更新间隔），$T_n = \sum_{i=1}^n S_i$。**计数更新过程** $N_t = \sup\{n : T_n \leq t\}$。**更新函数** $m(t) = \mathbb{E}[N_t]$。

**定理 131.3**（更新方程）：$m(t) = F(t) + \int_0^t m(t-s) dF(s)$，其中 $F$ 为 $S_1$ 的分布函数。此更新方程是更新理论的中心积分方程。

**定理 131.4**（关键更新定理 / Blackwell 定理）：若 $S_1$ 非格点分布且 $\mu = \mathbb{E}[S_1] < \infty$，则对任意 $h > 0$，
$$\lim_{t \to \infty} (m(t+h) - m(t)) = \frac{h}{\mu}$$
即更新过程的长期期望更新率趋近于 $1/\mu$。等待时间的分布收敛到"均衡分布"（stationary excess distribution）。

**定理 131.5**（Wald 方程，更新奖励过程）：设 $R_t = \sum_{i=1}^{N_t} Y_i$（$Y_i$ 为第 $i$ 次更新的奖励，$(S_i, Y_i)$ 独立同分布）。则 $\mathbb{E}[R_t] = \mathbb{E}[N_t] \mathbb{E}[Y_1]$，且 $\lim_{t \to \infty} R_t/t = \mathbb{E}[Y_1]/\mathbb{E}[S_1]$ 几乎必然。

---

*随机过程理论的核心从 Kolmogorov 相容性定理和连续性判别法出发，建立了过程存在性的基础框架。Poisson 过程以独立平稳增量刻画了"完全随机"的计数现象，其间隔时间呈指数分布（"无记忆性"）。Brown 运动作为连续时间随机过程的典范，其几乎处处连续无处可微的路径性质、二次变差为 $t$ 的特性以及鞅性质，催生了 Itô 随机分析这一全新的数学分支。Itô 公式作为随机微积分的基本定理（相当于确定性分析中的链式法则），将随机微分方程的求解转化为分析问题，为 Black-Scholes 期权定价公式和金融工程提供了数学理论支柱。Girsanov 定理的测度变换则在数理金融和统计推断中发挥着核心作用。Markov 过程理论以转移半群和无穷小生成元为工具，将微分方程与概率论紧密联系，而更新理论则是排队论和可靠性工程的数学基础。*
